Free, open-source media search for Telegram, on Windows

Find it by describing it.

Seekgram finds any photo, video or voice message in your Telegram account from a few words about what is in it. It runs on your own PC, and you search from a Telegram chat on any of your devices.

Download Seekgram Setup

Run the downloaded Setup. It installs without admin rights, starts with Windows and keeps itself up to date (you can switch that off in its Settings). Seekgram is not code-signed yet, so Windows SmartScreen may say Windows protected your PC: click More info, then Run anyway. The first start then downloads the search model and its tools, about 1.6 GB.

Or install from PowerShell

irm https://nominy.github.io/seekgram/install.ps1 | iex

Press Win, type PowerShell, press Enter, paste the line and press Enter again. It downloads the same Setup, checks its checksum and runs it. Options & uninstall

How it works

Three steps, and the second one you only do once.

1

Install

Paste the line above into PowerShell. Seekgram installs for your Windows user, starts with Windows and stays out of the way in the background.

2

Log in to Telegram

The Seekgram window asks for your free API key from my.telegram.org, your phone number and the login code, the same way a new Telegram app would. Then it starts going through your chats.

3

Search from a chat

Send ?pink dragon to your Saved Messages, from your phone or your PC. The ten best matches come back as an album, each with a link to the original message.

Search cheat sheet

Every search is a message that starts with ?, sent in your search chat: Saved Messages, or a private group of your own that the app can create for you.

?pink dragonFind pictures by words. Describe what is in them.
?video cat on a skateboardFind videos instead.
?audio rainFind voice messages and audio.
a photo with the caption ?Find pictures similar to that one. An album mixes its photos into one search.
? in reply to a photoMore like that photo. Works on a result you got earlier too.
?in snow as caption or replyThe photo plus the words: like this one, but in snow.
?moreThe next ten results.
?7Forward result number 7 itself, so you can jump to its chat.
?hereSent in a group where you are the only member: answer searches there from now on.
?Show this list in Telegram.

What you need

Seekgram runs a real AI model on your own computer, so it is pickier than most apps.

  • Windows 10 or 11, 64-bit. There is no macOS or Linux version.
  • Any DirectX 12 graphics card (NVIDIA, AMD or Intel); NVIDIA is no longer required. Without one the model runs on the processor: it works, but slowly.
  • About 6 GB of free disk space for the model, its tools and the index. The first start downloads about 1.6 GB.
  • A Telegram account, and a free API key from my.telegram.org (it takes a minute to create).
  • Patience the first time. Going through a large account takes hours to days. You can search what is already indexed while it runs.

Private by construction

Seekgram logs in as you and can see everything you can, so this is exactly what it does with that.

Everything runs on your PC

The model that looks at your media runs on your own graphics card. There is no Seekgram server and no account with us.

Media is not kept

Each photo, video or audio file is downloaded temporarily, turned into a list of numbers (a vector) and deleted. The index stores only those vectors and message IDs. A small, size-capped cache holds what a search needs to answer.

Nothing leaves your PC

Seekgram talks to Telegram, once to GitHub, NuGet and Hugging Face to download its model and tools, and every six hours to GitHub to look for a new version (you can switch that off). Nothing about you or your media is sent to anyone else. No telemetry.

Your login is protected

The Telegram login session and your API key are stored encrypted for your Windows user. Uninstalling with the purge option deletes them along with the index.

Questions

Anything else? Open an issue on GitHub.

How long does indexing take?

Hours to days, depending on how much media your account has and how fast your graphics card is. It runs in the background, pauses when Telegram asks it to slow down, and picks up where it left off after a restart. You can search what is already indexed at any time, and you can switch indexing off in the app when you need the graphics card for something else.

Does it read my messages?

It goes through every chat to find photos, videos and audio. Message text is not stored: the index holds only vectors and the IDs of the messages the media came from.

Can it send messages as me?

Only search results, and only into your own private search chat: Saved Messages, or a group in which you are the only member. It never writes anywhere else. If you later add someone to that group, they will see your results, so keep it to yourself.

Is it safe to give it my Telegram login?

Seekgram is a full Telegram client: it logs in as your account, like Telegram Desktop does. Install it only from this page or from the official releases; the code is open for anyone to check. You can end its session at any time in Telegram under Settings → Devices.

What if I edit or delete something in Telegram?

New media is picked up as indexing continues. Edits and deletions are not yet synced: a deleted message can still show up as a search result that no longer opens.

Why only Windows?

The model runs through DirectML, Microsoft's Windows-only graphics library, which works with NVIDIA, AMD and Intel cards. So far it has been tested on an NVIDIA card; if setup finds that your card cannot run the model correctly, Seekgram uses the processor instead and says so.

Can AI agents use my index?

Optionally. An MCP endpoint for AI agents is built in but switched off; it is under Settings → Advanced in the app. See the README.

How do I remove it?

Use Settings → Apps → Seekgram → Uninstall. That stops Seekgram and keeps your Telegram login, index and the downloaded model in %LOCALAPPDATA%\Seekgram, so a reinstall continues where you left off. To delete those as well, run this in PowerShell instead: & ([scriptblock]::Create((irm https://nominy.github.io/seekgram/install.ps1))) -Uninstall -Purge

How does it stay up to date?

Every six hours Seekgram asks GitHub whether there is a new release. If there is, it downloads it in the background, stops cleanly and restarts on the new version; your login and index are kept. Switch this off in the app under Settings → Install updates automatically.
